# 브랜드 스타일 (LG)

## Decisions

- 화면은 LG 스타일로 칠합니다. 주요 색은 LG Red(라이트 `#A50034`, 다크 `#C8285A`)이고, 따뜻한 연회색 면(라이트 `#F6F3F2`)과 진한 검정 글자(`#111111`)를 함께 씁니다. 정확한 토큰 값은 `app/globals.css`의 semantic token이 기준입니다.
- LG Red는 화면의 주된 실행 버튼(`primary`)에만 씁니다. 보조 버튼, 선택된 토글, 링크, 일반 강조에는 쓰지 않습니다. 선택된 토글은 `foreground` 바탕으로 칠합니다.
- 버튼, 입력창, 토글은 알약 모양(완전히 둥근 모서리)입니다. 카드는 크게 둥근 모서리(약 20px)에 옅은 그림자를 둡니다.
- 화면 제목은 본문보다 확연히 크고 굵게 씁니다. 한국어 제목은 단어 단위로 줄을 바꿉니다(`word-break: keep-all`).
- 서체는 LG Smart, LG EI를 먼저 지정하고, 없으면 시스템 한글 서체로 대신합니다.

## Boundaries

- 색과 모양만 정합니다. component 선택과 화면 구성은 [ui-composition](ui-composition.md)을 따르고, LG 스타일은 shadcn component의 token과 variant로 입힙니다.
- LG 로고와 LG 이름을 넣은 로고 마크는 쓰지 않습니다.
- 오류 표시는 `destructive` token을 씁니다. LG Red로 대신하지 않습니다.

## Why

사용자가 shadcn 기본 회색조 화면과 LG 스타일 화면을 나란히 비교한 뒤 LG 스타일을 골랐습니다. 회색조 기본값은 어느 회사 서비스인지 드러나지 않고 개발 도구처럼 보였습니다. 빨강을 실행 버튼에만 쓰는 이유는, 빨강이 여러 곳에 퍼지면 어떤 버튼을 눌러야 하는지 흐려지고 오류 표시와도 헷갈리기 때문입니다.

## Reconsider when

- 회사 브랜드 가이드라인이 사내 도구에 LG 색이나 이름을 쓰지 못하게 하거나, 다른 색 값을 지정할 때
- LG 전용 서체 파일을 프로젝트에 넣을 수 있게 될 때(서체 대체를 다시 봅니다)

## Still-rejected alternatives

- shadcn 기본 회색조(neutral) 그대로 쓰기 — 브랜드가 드러나지 않습니다. 브랜드 가이드라인이 LG 스타일을 막으면 다시 봅니다.
