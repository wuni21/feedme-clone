# URL → Markdown 변환 후 LLM으로 보내기

웹 페이지 URL을 붙여넣으면 본문만 Markdown으로 뽑아 보여 주고, 복사·다운로드하거나 프롬프트와 함께 ChatGPT·Claude로 바로 넘길 수 있게 한다.

## 연결된 자료

- [prototype.html](prototype.html) — 승인된 화면 구성. 화면 배치, 요소 순서, 상태별 모습(빈 화면·변환 중·결과·저자 없는 결과·오류 3종), 문구, 좁은 화면에서 쌓이는 순서를 정한다. 프로토타입 안의 데이터와 지연 시간은 더미다. 시험용으로 URL에 `fail`/`login`/`docs`를 넣으면 상태가 바뀌는 동작은 제품 동작이 아니다.
- [docs/decisions/ui-composition.md](../../decisions/ui-composition.md) — 일반 UI는 shadcn/ui component로 구성하고 semantic token을 쓴다.
- [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md) — 새 의존성(defuddle 등)의 버전 범위를 정하는 기준이다.

## 사용자가 얻는 결과

- URL 하나로 페이지의 광고·메뉴를 뺀 본문을 Markdown으로 얻는다.
- 제목과 저자로 맞는 페이지를 변환했는지 바로 확인한다.
- 버튼 하나로 복사하거나 `.md` 파일로 저장한다.
- 프롬프트를 고르거나 직접 써서 ChatGPT나 Claude 새 대화에 붙여넣기만 하면 되는 상태가 된다.
- 라이트·다크 모드를 오가며 쓴다.

## 범위

한 화면짜리 서비스다. 화면 구성은 prototype.html을 따른다.

1. **입력**: URL 입력창과 "변환하기" 버튼. 입력창에 글자가 있으면 지우기(×) 버튼이 보인다.
2. **변환**: 서버가 페이지를 가져와 defuddle로 본문을 Markdown으로 뽑고, 제목과 저자도 함께 얻는다.
3. **결과 확인**: 제목, 저자(값이 있을 때만), 원본 URL 링크를 담은 헤더와 렌더링된 Markdown 본문.
4. **내보내기**: 복사하기, `.md` 다운로드, ChatGPT로 열기, Claude로 열기.
5. **프롬프트**: 프리셋 "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘"와 "직접 입력". 아무것도 고르지 않아도 된다.
6. **다크 모드 토글**: 헤더에 있다.

## 수용 기준

입력
- 입력창이 비어 있으면 "변환하기" 버튼을 누를 수 없다.
- 입력창에 글자가 있으면 지우기 버튼이 보이고, 누르면 입력값, 결과, 오류가 모두 사라져 빈 화면으로 돌아가며 입력창에 포커스가 간다.
- Enter 키로도 변환을 시작한다.

변환
- `http://` 또는 `https://`로 시작하지 않는 등 URL 형식이 아니면 서버에 요청하지 않고, 입력창 아래에 "http:// 또는 https://로 시작하는 올바른 URL을 입력하세요."를 보여 준다. 입력을 고치기 시작하면 이 문구가 사라진다.
- 변환하는 동안 버튼은 "변환 중"으로 바뀌고 눌리지 않으며, 결과 자리에 로딩 모양(skeleton)이 보인다.
- 페이지를 가져오지 못하면(응답 없음, 4xx/5xx, HTML이 아님) "페이지를 가져오지 못했습니다" 알림을 보여 준다. 설명에 가능하면 HTTP 상태 코드를 넣는다.
- 가져왔지만 뽑을 본문이 없으면 "본문을 찾지 못했습니다" 알림을 보여 준다.
- 실제 공개 페이지(예: https://defuddle.md/docs, https://en.wikipedia.org/wiki/Markdown)를 넣으면 제목, 저자, 렌더링된 본문이 나온다.

결과
- 헤더에 제목, 저자(값이 있을 때만, 날짜가 있으면 함께), 원본 URL 링크가 보인다. 링크는 새 탭에서 열린다.
- 저자가 비어 있는 페이지(예: https://react.dev)는 저자 줄 없이 제목과 링크만 보인다.
- 본문은 제목, 목록, 인용, 코드 블록, 표, 링크, 이미지가 서식대로 렌더링된다.

내보내기
- "복사하기"를 누르면 `# 제목` 다음 빈 줄, 그 아래 Markdown 본문이 클립보드에 들어간다. 버튼은 잠시 "복사됨"과 체크 아이콘으로 바뀐다.
- ".md 다운로드"를 누르면 복사와 같은 내용이 페이지 제목을 이름으로 한 `.md` 파일로 저장된다. 파일 이름에 쓸 수 없는 문자는 빼고, 제목이 없으면 `untitled.md`를 쓴다.
- 복사와 다운로드에는 프롬프트가 들어가지 않는다.
- "ChatGPT로 열기"/"Claude로 열기"를 누르면
  - 프롬프트를 골랐으면 [프롬프트, 빈 줄, 복사 내용]을, 고르지 않았으면 복사 내용만 클립보드에 넣는다.
  - 새 탭으로 ChatGPT(https://chatgpt.com/) 또는 Claude(https://claude.ai/new)의 새 대화를 연다.
  - "붙여넣기(Ctrl+V)만 하세요"라는 안내 토스트를 보여 준다.

프롬프트
- 프리셋과 "직접 입력"은 한 번에 하나만 고를 수 있고, 고른 것을 다시 누르면 해제된다.
- "직접 입력"을 고르면 텍스트 입력창이 나타나고 포커스가 간다. 다른 것을 고르거나 해제하면 입력창이 사라지고 내용도 지워진다.
- 직접 입력한 내용은 저장하지 않는다. 새로고침하거나 다른 페이지를 변환하면 사라진다.
- "직접 입력"을 골랐지만 비어 있으면 프롬프트 없이 보낸다.
- 보내기 버튼 옆 한 줄에 무엇을 보내는지 보여 준다("“요약해줘” + 본문 Markdown을 보냅니다" / "본문 Markdown만 보냅니다").
- 새 페이지를 변환하면 프롬프트 선택이 초기화된다.

다크 모드
- 헤더의 버튼으로 라이트와 다크를 오간다. 아이콘과 접근성 이름("다크 모드로 전환"/"라이트 모드로 전환")이 현재 상태에 맞게 바뀐다.
- 두 모드 모두 프로젝트의 semantic token(`app/globals.css`의 `:root`와 `.dark`)으로 칠해진다.

화면 크기
- 좁은 화면(약 640px 이하)에서는 입력창과 변환 버튼, 결과 헤더와 내보내기 버튼이 세로로 쌓이고, 버튼을 숨기지 않는다.

## 정해진 제약과 이유

- **본문 추출은 defuddle로 한다.** 사용자가 정한 필수 조건이다. 0.19.6에서 확인한 결과, `defuddle/node`의 `Defuddle(html, url, { markdown: true })`에 HTML 문자열을 넘기면 `content`(Markdown), `title`, `author`, `site`, `wordCount`가 나온다. 문서는 Node에서 `package.json`에 `"type": "module"`이 필요하다고 적고 있다. 이 프로젝트의 Next.js 서버 환경에서 그대로 동작하는지는 구현에서 확인해야 한다.
- **페이지는 서버에서 가져온다.** 브라우저에서 다른 사이트를 직접 가져오면 CORS에 막히기 때문이다.
- **LLM에는 클립보드 + 새 탭으로 넘긴다.** URL의 `?q=`로 입력창을 미리 채우는 방식은 주소 길이 제한 때문에 긴 본문이 잘리거나 열리지 않는다. 이 서비스는 localhost에서 돌기 때문에 LLM이 링크로 본문을 읽어 갈 수도 없다. 그래서 길이와 상관없이 항상 같은 방식으로 동작하는 클립보드 방식을 골랐다(사용자 확정).
- UI는 shadcn/ui component를 쓴다(Button, Input, Field, Card, Alert, Empty, Skeleton, Toggle Group, Sonner 등). LLM 보내기 칸만 기존 component를 조합한 프로젝트 전용 구성이다.

## 가정 (바꿔도 되는 기본값)

- 복사·다운로드 내용은 `# 제목` + 본문이다. 저자나 원본 URL은 넣지 않는다.
- 다크 모드는 처음에 시스템 설정을 따르고, 사용자가 토글로 고른 값은 이 브라우저에 기억한다.
- 서버가 페이지를 기다리는 시간은 약 15초로 하고, 넘으면 "페이지를 가져오지 못했습니다"로 처리한다.
- 페이지를 가져올 때 일반 브라우저와 비슷한 User-Agent를 보낸다. 기본값으로 보내면 막는 사이트가 많기 때문이다.
- UI 문구는 한국어이고, 서비스 이름은 FeedMe로 표시한다.
- 변환 기록이나 결과는 저장하지 않는다. 새로고침하면 빈 화면으로 돌아간다.
- 클립보드 쓰기가 실패하면 "복사하지 못했습니다" 오류 토스트를 보여 주고, ChatGPT·Claude 버튼이면 새 탭도 열지 않는다.

## 다루지 않는 것

- 로그인이 필요하거나 스크립트로만 그려지는 페이지의 본문 추출(헤드리스 브라우저 렌더링). "본문을 찾지 못했습니다"로 안내하는 것으로 충분하다.
- 변환 기록, 계정, 프롬프트 저장. 직접 입력 프롬프트는 1회용이라는 요구 때문이다.
- ChatGPT·Claude 외 다른 LLM, API로 직접 보내기.
- 원본 Markdown 편집이나 원문/렌더링 전환 보기. 요청 범위에 없다.
- 스펙이 요구하지 않은 보안 하드닝(내부망 주소 차단 등), 속도 제한, 캐시. 학습용 템플릿의 검증 예산(AGENTS.md)에 따른다.

## 남은 위험

- 일부 사이트는 서버에서 보낸 요청을 막는다(403, 봇 차단 페이지). 이때 사용자는 오류만 보고 본문을 얻지 못한다.
- 봇 차단 페이지가 200으로 응답하면, defuddle이 그 차단 문구를 본문으로 뽑아 "결과"처럼 보일 수 있다.
- 새 탭 열기가 팝업 차단에 걸리면 클립보드에만 내용이 남는다.
